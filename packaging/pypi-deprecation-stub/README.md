# sap-adt — DEPRECATED

This PyPI project was renamed to **[`sap-adt-cli`](https://pypi.org/project/sap-adt-cli/)**.
PyPI cannot rename a project, so this name remains as a metadata-only
deprecation stub.

- Install or upgrade the CLI with `pip install "sap-adt-cli>=1.5.0,<2.0.0"`.
- The installed command is unchanged: **`sap-adt`**.
- `pip install -U sap-adt` still works for one transition: this stub depends
  on the matching `sap-adt-cli` release.

No code lives in this distribution.
